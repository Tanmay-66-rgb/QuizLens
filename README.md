# QuizLens

🔍 QuizLens – AI-Powered MCQ Quiz Generator

Turn your documents into quizzes. Learn smarter, test yourself better.

QuizLens is a web-based application that transforms uploaded documents into multiple-choice quizzes (MCQs). Instead of manually preparing questions from lengthy study materials, users can simply upload a document and generate a quiz to test their understanding.

Whether you're a student preparing for exams, a teacher creating assessments, or someone learning a new topic, QuizLens makes quiz creation faster and easier.

🌐 Live Demo

🚀 Try QuizLens : https://mcq-quiz-generator.netlify.app/

✨ Features

📄 Document Upload: Upload documents to generate quizzes from your study materials.

🧠 AI-Powered Quiz Generation: Automatically generates MCQs based on document content.

📝 Multiple-Choice Questions: Get structured questions with multiple answer options.

🎯 Self-Assessment: Test your knowledge and understanding.

🚀 How to Use

1. Open QuizLens using the live demo link.

2. Upload your document.

3. Generate an MCQ quiz.

4. Answer the generated questions.

5. Use the quiz to evaluate your understanding.

🎯 Project Objective

The main objective of QuizLens is to simplify the process of creating practice quizzes from educational documents.

It aims to make studying more interactive, reduce manual effort, and help students prepare more effectively for examinations.
